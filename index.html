How it plays

↕

Run the corridor

Swipe up and down a long hallway lined with bowls and cat flaps.

↔

Swat the wrong ones

Each cat only eats from its own colour. Swipe away any cat heading for the wrong bowl.

+

Tap an empty bowl to refill it, before a hungry cat storms off.

x5

Feed cats in a row to stack your multiplier, then brag on the Game Center leaderboard.
